# Animasi 3D Tata Surya (PyOpenGL)

Project ini merupakan animasi 3D Tata Surya yang dibuat menggunakan PyOpenGL sebagai penerapan konsep dasar grafika komputer. Animasi menampilkan Matahari sebagai pusat tata surya dan planet-planet yang mengorbit di sekitarnya dengan menggunakan transformasi 3D, pencahayaan, texture, dan animasi.

## Cara Menjalankan

1. Pastikan Python 3 sudah terpasang.
2. Install library yang dibutuhkan:

   ```
   pip install PyOpenGL PyOpenGL_accelerate Pillow
   ```

3. Jalankan program:

   ```
   python main.py
   ```
